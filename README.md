# 🎮 Epic Noughts & Crosses

A real-time online multiplayer Noughts and Crosses (Tic-Tac-Toe) game with competitive features, customisation, and live spectators.

👉 **Play now:** https://epic-noughts-and-crosses-production.up.railway.app/

---

## 🚀 Features

### 🌐 Multiplayer
- Real-time online 1v1 gameplay
- Public and private game lobbies
- Join games instantly via shareable links
- Spectator mode (watch live matches)
- Host controls (kick players)

### 🏆 Competitive
- Leaderboard tracking:
  - Wins
  - Draws
  - Losses
- Persistent player stats

### 👤 Accounts
- Simple account system (username + password)
- User-based stat tracking

### 🎨 Customisation
- Theme settings for personalised UI
- Clean and responsive interface

### ✨ Game Experience
- Smooth real-time updates
- Win and lose animations
- Clear game states and transitions

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript  
- **Backend:** Node.js, Express  
- **Real-time:** WebSockets (Socket.IO)  
- **Database:** SQLite  
- **Hosting:** Railway
